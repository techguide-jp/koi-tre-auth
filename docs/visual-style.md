# Koi-Treの画面スタイル

## 方向性

「恋愛小説のような、落ち着いた温かさ」。アイボリーを土台に、ローズを会話への誘いや大切な変化、セージを成長・落ち着きに使う。本文は濃いプラム色、補足はコントラストを保ったグレーにする。人物の個性は服装・仕草・持ち物で表し、過度な装飾を重ねない。

## 日本語の文字

- 見出し：[しっぽり明朝](https://fonts.google.com/specimen/Shippori+Mincho)。日本語の柔らかさと物語らしさを表す。
- 本文・操作：[Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP)。説明と操作の読みやすさを優先する。
- 既存のRoboto指定を日本語フォントの配信へ置き換え、Google Fontsの`display=swap`と日本語の端末フォントへの代替を設定する。英語のブランドロゴとコード用書体は用途に応じて分ける。
- `styles.css`でサイズを共通管理。通常本文16px、補足14px、小ラベル13px。大見出しは画面幅に応じて30〜44px、中見出し24〜32px。入力欄は16pxを確保する。個別のグラフ数値・カード名は役割に応じたサイズを残す。
- 訪問済みリンクも同じ配色にし、古いSMUIの青色が混ざらないようにする。

## 人物の紹介

ホームと料金ページの紹介には、性格ごとに異なるバストアップ画像を使う。あおいはカメラ、りんは開いた手で語りかける、しおりは本、ゆうはコーヒー、そうたは明るい挨拶、れんは落ち着いた仕草。男女の事前選択は維持する。

画像の列定義と代替テキストは`src/lib/character-introductions.ts`、素材仕様は`static/images/characters/README.md`を参照。会話中の6表情、好感度の反応、通常・特別カードは既存の素材を使う。

## 使い方の構成

最初に「選ぶ・話す・振り返る」の3ステップをカードで提示。3往復と6往復を並べて比較し、25点評価と4パートの流れを視覚的に案内する。無料範囲、利用枠、採点・好感度・XP、再練習、カスタム場面、データの扱いは質問ごとの開閉欄にまとめる。実装・サービス名の詳しい説明は開閉欄に置く。

## 確認記録

ローカル専用DB・Firebase Auth Emulator・架空会話の応答を使用。本番データや実在ユーザーのアカウントを使わず表示と操作を確認した。採点品質・実モデル評価の検証記録ではない。

- ホーム、料金、使い方、マイページ、アルバム、会話ネタ帳、30秒お試しを幅360 / 390 / 768 / 1440pxで確認。横にはみ出さず、表示中の文字は13px以上。
- PCは男女それぞれ3人、スマホはホームの人物タブ切替と料金ページの縦並びを確認。男女6人のポーズと名前・代替テキストの対応を確認。
- Noto Sans JP・しっぽり明朝の実際の読み込みを確認。フォントが使えない場合の日本語代替指定を維持。
- 3往復の生成・保存・完了をローカルで確認。会話中は既存の表情画像が笑顔→考え中→安心へ切り替わり、入力欄は16px。
- 架空の保存済み25点評価で、PC・スマホのレーダーチャートと開閉できる分析を確認。スマホでは得点を独立した行へ置き、見出し・ラベルの窮屈な折り返しを解消。
- 使い方の詳細は初期状態で閉じ、クリックとキーボードで開閉できる。体験ボタンはホームの人物選択へ移動。
- 本番の購入停止を維持。UI変更ではDB・採点・好感度・課金の計算ルールを変更しない。
