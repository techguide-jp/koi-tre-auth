# 人物設定を更新する

マイページの「運営管理」から「人物設定」を開く。直接URLは `/admin/characters`。権限は評価方針・知識と同じサーバーの管理者UID許可リストで制限する。

## フォームを分けて編集する

人物を一人選び、次の項目を個別に編集・下書き保存する。

| 項目           | 編集する内容                                               |
| -------------- | ---------------------------------------------------------- |
| プロフィール   | 性格・人柄、好きなこと、会話に使う背景                     |
| 価値観・距離感 | 大切にすること、嬉しい接し方、戸惑う接し方                 |
| 話し方         | 言葉遣い・テンポ、一人称、表現の傾向                       |
| 関係段階       | 出会い編・デート編・本音編・気持ちを伝える編・本編後の日常 |
| 場面別の反応   | 9種類の場面ごとの返信方針と、任意の参考セリフ              |
| 好感度のセリフ | 長所の観点別・共通・回復・戸惑い・低下の結果セリフ         |

人物の名前・年齢・画像は既存の6人のカタログを使う。この画面では会話用の人物像を整える。一般画面の紹介文は既存カタログの文面を維持する。

未保存の変更がある場合は、保存か「この項目の変更を戻す」を行ってから他の項目・人物へ移る。別タブから同じ人物を更新した場合は保存を拒否し、古い内容で上書きしない。

## 返信を確認して公開する

1. 編集した各項目の下書きを保存する。
2. その人物の本編から確認する場面を選び、話しかける言葉を入力する。
3. 「この人物の返信を試す」でAIの返信を確認する。AI利用は発生するが、練習枠・XP・好感度は消費・変更しない。
4. 内容がよければ確認欄にチェックし、その人物の設定を公開する。

公開する内容と、返信確認した下書きのリビジョン・内容ハッシュ・確認した管理者が一致する場合だけ公開できる。保存し直すと以前の確認は無効になる。過去の公開版へは「公開の履歴」から人物単位で戻せる。

## 会話への使われ方

新しく始まる練習は開始時に人物設定のスナップショットを保存する。未公開の人物は既存設定を初期値として保存する。公開・復帰の後も開始済みの会話、再開、再送、言い直しは元の設定を使う。導入前の練習は従来の設定を使い続ける。

現在の話に対応する関係段階と場面の反応だけを返信用の人物紹介へ組み立てる。本音編へ戻る再練習に未来の交際設定を渡さない。参考セリフは表現の参考で、固定返信にはしない。本人の事実と意思、場面の関係、双方の境界を優先する。

人物設定はDifyの相手役へ渡し、Jevの25点の評価条件へ追加しない。好みが一致することや人物に合わせ続けることを新しい採点項目にしない。結果画面には開始時の設定のリアクション文を使い、人物設定全文は一般利用者のAPIへ返さない。

## 追加反映に必要なもの

- migration `0008_woozy_human_fly`：人物設定の下書き・公開履歴、練習の設定スナップショット。
- 管理者UIDは既存の `KOITRE_ADMIN_UIDS` を利用。新しい管理権限・環境変数は追加しない。
- 既存Dify Workflowの `partnerDescription` 入力を使用するため、Workflow変更・Difyアプリ追加は不要。
- 本番DBとアプリの追加反映前に、独立DBのmigrationとUI・回帰テストを確認する。本番決済は停止を維持する。
