# カスタム場面

> 振り返りの最新実装は [会話分析の仕様](conversation-analysis.md) を参照してください。以下の定型句を使う言い換えは初回公開時の記録です。

## 体験と利用ルール

トップの3場面に加え、「自分の場面をつくる」フォームを用意する。必須は状況（500文字まで）のみ。相手の呼び名（20文字まで、未指定は「はる」）、相手の最初のひと言（200文字まで）は任意。最初のひと言がない場合は、利用者から話し始める案内を表示する。

未ログインでも設定できる。ログインボタン操作前に設定を確認でき、取消・再読み込みでも同じタブで入力を保持する。3回返答・最初の生成と保存成功で1練習消費・月10回のルールは共通。有料枠は新設しない。

## 保存とAPI

`practices`にnullableのJSONB `custom_scene`を追加。`scene_id=custom`の時だけ、正規化した状況・呼び名・最初のひと言を保存する。既存の3場面と履歴は変更しない。練習開始後に場面を書き換えるAPIは追加しない。

作成APIで長さ・型を検証。認証ユーザー本人の練習だけに保存する。同じ作成IDの再送は同一設定だけ受け付け、設定が異なる場合は409。クライアント側の作成IDも設定ごとに分ける。状態取得・生成・同じ場面の再練習は保存した設定を利用する。

自由記述はDifyへの練習データとして渡す。固定の出力形式・安全性・3回返答の規則を変更する命令として扱わない。利用者のGoogleプロフィールは渡さない。会話や場面本文をGAへ送らない。

## 検証と公開

入力検証、異なる設定での再送、所有者以外の参照拒否、保存・再開・再練習、生成コンテキストをテストする。migrationを生成・確認し、ローカル適用と再生成で差分なしを確認する。Difyでカスタム場面を実行してから、追加カラムを本番適用し、Vercelの確認用デプロイを経て切り替える。旧版は追加カラムを参照しないため切り戻し可能。
