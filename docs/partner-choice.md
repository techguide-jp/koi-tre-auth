# 練習相手の選択（2026-11-02）

従来も利用者の性別による利用制限はなく、Difyには性別・性的指向を推測しない指示がある。ただし画面上で女性も利用できることや、男性の相手との練習を選ぶ方法が分かりにくかった。

## 変更

- 初対面のカフェ、趣味・休日、デート中の沈黙の各カードに、練習相手の「性別を指定しない／男性／女性」を追加する。
- 指定なしは従来の場面と相手をそのまま使う。男性を選ぶと、カフェはゆう、趣味はそうた、沈黙はれん。女性は従来のはる・あおい・りん。名前から性別を推測するのではなく、指定した設定をAIへ渡す。
- 相手を指定した場合は、既存のカスタム場面形式に、場面・相手の性別・呼び名・最初のひと言をまとめる。ログイン前のタブ内保存、作成APIの検証、DB保存、再開、再練習は既存の仕組みを使う。既存API・DBスキーマ・migrationの変更はない。
- 場面カードからの設定は専用のタブ内保存領域を使い、自由入力中のカスタム場面の下書きを上書きしない。
- 利用者本人の性別・性的指向を登録させず、選んだ相手から推測しない。女性同士、男性同士の練習も制限しない。Googleプロフィールを生成入力へ追加しない。相手の選択をGA4の属性として送信しない。
- LP・FAQ・使い方・検索用説明に性別を問わず利用できる案内を追加する。自由記述の場面でも相手を指定できることを説明する。
- 開始処理中は元の場面カードに「準備しています…」を表示し、再操作と相手の切り替えを防ぐ。

型チェック・lint・69件のテスト・ビルドを通過。全3場面×男女の設定が既存形式の入力検証を通り、呼び名・開始文・状況が再構成されることと、生成リクエストに設定が渡ることを追加検証した。テストDBでも、選んだ男女それぞれの相手を再開・完了・再練習まで保持し、利用枠の消費が従来どおりであることを確認した。自由入力の下書きと相手選択の下書きが独立する回帰テストも追加。

ローカルの本番ビルドで、男性のカフェ相手（ゆう）と趣味の相手（そうた）の選択・ログイン画面への引き継ぎを確認。公開8ページのSEOチェックも通過した。
