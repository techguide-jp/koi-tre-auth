# 雑談で互いを知る力の評価

## 対象と方針

初対面・趣味の練習では、質問に沿う回答と、相手が話せる材料を返す行動を区別する。「漫画を読んでいます」「キングダムです」と名前・事実だけの回答が続き、相手の質問だけで話題が展開した場合は、後で好きな理由を伝えた強みと、前半の受け渡しの改善を併記する。短い一言でも、具体的な感想や相手への関心が伝わるなら評価する。質問や冗談の回数、発言の長さでは採点しない。

5観点・25点の構成は維持する。キャッチボールでは互いが話すきっかけを作る行動、話題のつながりでは同じ話題に沿うだけの返答と、その話題を自然に広げる返答の差を見る。自分の伝え方は、本人が語った理由・感じ方・具体性を扱う。配慮、断り、約束成立後の締め、沈黙の基準は維持する。

## 反映と互換性

- 知識の公開内容に任意の `coaching: reciprocal-small-talk-v1` を持たせ、初対面・趣味の場面にだけ適用する。指定なしは従来方式。開始済み会話・再評価はその練習に固定した版を参照する。旧JSON・ハッシュ・数値評価・進行履歴は書き換えない。
- Jevの固定基準と、Difyの既存の `policy_context.core`・場面指示をそろえる。Difyの公開Workflow、入出力形式、認証、DBスキーマ、合格点・好感度のルール、決済は変更しない。
- 文章分析は、根拠がある場合に該当する本人の返答を引用し、改善点と次の練習へつなげる。名前だけの返答には、同じ会話の本人発言に基づく理由・感想を添える案や、相手へ話を渡す案を出す。別案は語尾の差だけにせず、未発言の経験・好意は作らない。会話中の相手役も、感想や自分の好みを返して関心を向けやすい材料を出す。

## 確認と公開条件

- 同じ「キングダムです」を含む架空の3往復で、新旧の評価・分析・言い換えを比較する。名前だけが続く例と短くても互いに関心を返す例を対照にし、短い断り・自然な締め・沈黙を過小評価しないことも確かめる。
- 自動テストは対象場面、旧公開版の互換性、再評価の版固定、JevとDifyへ渡る方針、3/6往復の入力制限を確認する。生成結果の質は実AIのサンプルを読んで確認し、テストの成功とは区別する。
- コードが公開された後、最適化した内容を下書きに保存し、実AIで確認してから新しい練習へ公開する。旧公開版へ戻せる状態を保つ。課金停止を継続する。
- 新版の公開後に切り戻す場合は管理画面で旧公開版へ戻す。新版で開始済みの練習を続けられるよう、新版を読めるアプリは維持する。

## 実Jevによる比較

2026-11-11に、[架空の会話](evaluations/scene-coaching-cases.json)を同じ場面・同じ会話本文で `jev-1.14.0` に送り、旧公開方針と新版候補を比較した。下表はキャッチボールの5点満点の目安。合計点や実際の人間関係での効果ではない。

| 会話                               | 旧公開方針 | 新版候補 |
| ---------------------------------- | ---------: | -------: |
| 名前・事実だけの返答が続く         |       3.28 |     1.75 |
| 「キングダムです」から理由を答える |       3.69 |     2.21 |
| 短くても互いに関心を返す           |       4.14 |     3.35 |
| 自分の帰る意思を保つ               |       4.90 |     4.91 |
| 静かな時間を楽しむ                 |       4.82 |     4.82 |

新版では、雑談の受け渡しがある例と、相手の質問に頼る例との差が広がった。相互性のある例も旧基準より低めに出ており、数値をそのまま旧版の伸び幅として比較しない。断り・沈黙の観点別指示は同じで、個別の実行にはばらつきがある。趣味の短い例では配慮の根拠が足りず、未評価を0点へ置き換えなかった。
