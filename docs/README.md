価値観・方針の更新方法は [評価方針と知識の運用](knowledge-policy-admin.md)。基本方針と場面別の知識をKoi-Tre管理画面から保存・確認・公開し、新しく始まる練習に適用する。

## 現行仕様を読む

料金再設計の決定仕様と今回の実装は[月額中心の料金・利用権・利用枠](billing-plans.md)。Plusのみで本編攻略・再練習を可能にし、追加共通15枠550円を導入する。公開済み状態とは分け、公開確認後に反映状況を更新する。

現行の本編は6人×12話。3往復は1枠、6往復は2枠。無料枠は毎月10枠、ルートパックは1人1,480円・人物専用24枠、Plusは月980円・更新ごと共通60枠という承認済み仕様。本番の有料購入は準備中で、購入権や有料枠の付与確認はStripeサンドボックスと独立DBで行った。
