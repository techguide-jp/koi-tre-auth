各画像は1254×1254 RGBA。3列×2行の等分セルで、各セルは418×627。全身の頭から腰までを同じ位置に収め、CSSの表示範囲を切り替える。

## 制作指示

新規制作：日本の恋愛コミュニケーション練習アプリ用の成人キャラクター、統一した温かなノベルゲーム調のイラスト。正方形の外枠に3列2行の等分セル。各セルは頭全体・肩・上半身から腰までのバストアップ。同じ人物の髪型・服装・顔の位置と大きさを保ち、上記6表情を順番通りに描く。背景は透明。文字・枠・小道具・他の人物は描かない。

人物指定：あおい25歳（肩までの栗色の髪、セージ色のカーディガンと生成りのトップス）、りん28歳（黒いボブ、テラコッタ色のジャケット）、しおり31歳（長い黒髪、細い丸眼鏡、紺のニット）、ゆう26歳（柔らかな短い茶髪、オートミール色のシャツと緑のトップス）、そうた29歳（少し動きのある短い黒髪、錆色のシャツ）、れん32歳（整えた黒髪、チャコール色のカーディガン）。

腕の変更：元画像を参照して人物・顔・服・配色・表情・等分セルを保持し、腕と手だけを上記の自然な動作へ変更。指は自然な5本、手を顔に重ねず、セルの外に出さない。全セルで頭と体の尺度を固定する。
