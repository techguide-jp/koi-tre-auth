# 6往復の場面専用イラスト

Koi-Treの既存キャラクターを参照し、組み込みの `image_gen` で制作した背景付きの場面イラスト。全6人、276セルを24枚のWebPアトラスに収録する。通常3往復の立ち絵とは別の画像を使用する。

| ファイル（各人物ID） | 配列    | 場面の順序                       |
| -------------------- | ------- | -------------------------------- |
| `{id}-story.webp`    | 3列×4行 | その人物の本編1〜12話            |
| `{id}-practice.webp` | 2列×5行 | 共通6場面、日常4場面のカタログ順 |
| `{id}-season-1.webp` | 3列×4行 | 1〜6月、各月の前半・後半         |
| `{id}-season-2.webp` | 3列×4行 | 7〜12月、各月の前半・後半        |

人物IDは `aoi` / `rin` / `shiori` / `yu` / `sota` / `ren`。セルは左上から行ごとに読む。季節の絵は年をまたいで同じ月・場面に対応する。画像は `cwebp` で配布用に圧縮し、描画時にCSSで該当セルを切り出す。全ファイルで約10MB。1場面の表示で全アトラスを取得することはない。

制作時は `static/images/characters/{id}-poses.png` を人物・作風の参照に使用した。プレイヤーの容姿を固定せず、会話にない交際成立等を画像で断定しない構図としている。

正確な制作プロンプト・参照画像・セルごとの場面ID・保存先は [制作プロンプト一覧](../../../docs/special-card-art-prompts.json)、表示と検証は [仕様と検証記録](../../../docs/special-card-art.md) を参照する。対応関数は `src/lib/special-card-art.ts`。保存済みの6往復完了履歴で表示し、点数やミッションの成否では制限しない。既存の6往復カードも対象で、DB変更や追加の生成API利用は不要。
